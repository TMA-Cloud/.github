# Contributing

Thanks for your interest in TMA Cloud! We're super excited to have you here. This document contains the best practices for contributing to our repositories.

## Filing an issue

When reporting a bug, include your TMA Cloud version, how you run it (Docker or manual), steps to reproduce, and any relevant logs.

**Have a feature idea? Open an issue before making a PR** so we can discuss the design before you spend time on it. Small fixes like typos don't need an issue.

**Found a security issue?** Don't open a public issue. See [SECURITY.md](SECURITY.md).

## Making a pull request

For anything bigger than a small fix, open an issue first so we can agree on the approach before you start. This helps make sure the work you put into your pull request gets merged.

## Conduct

This project follows the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold it.
