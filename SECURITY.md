# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public issues.**

Report them privately using GitHub's [Report a vulnerability](https://github.com/TMA-Cloud/TMA/security/advisories/new) form, or email [zidan@tma.bd](mailto:zidan@tma.bd).

Please include the affected version, steps to reproduce, and the potential impact. We will acknowledge your report as soon as possible and keep you updated on the fix.

Issues caused only by an insecure self-hosted setup, such as weak secrets or an exposed `.env` file, are not considered vulnerabilities in TMA Cloud.
